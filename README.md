# Formation SEO/GEO HEC Paris : vos outils

Page d'installation des extensions Chrome pour la formation SEO/GEO de HEC Paris (18 et 19 novembre 2026), préparée par Empirik.

En ligne : https://pribeaucourt.github.io/formation-hec/

Hors ligne : décompressez ce dossier, puis ouvrez index.html dans Chrome. Tout fonctionne sans connexion, sauf les liens vers les sites extérieurs.

La liste des extensions a été validée par la DSI de HEC Paris en juillet 2026. Toute extension ajoutée à la page doit l'être aussi.
